# Google Ad Manager MCP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship `gam-mcp` — a Node.js MCP server installable via `npx` that exposes Google Ad Manager (GAM) revenue and inventory analytics as LLM tools, per the spec at `docs/superpowers/specs/2026-04-30-gam-mcp-design.md`.

**Architecture:** Layered TypeScript application — pure utility modules (dates, errors, output) → mockable GAM client interface → tools (one file each, registered with the MCP SDK) → server + CLI entrypoint. Reports are async (create job → poll → download); large results spool to temp files, small results return inline. Opinionated tools share a `buildReportTool` factory to avoid copy-paste across the seven analytical tools.

**Tech Stack:** Node.js 20+, TypeScript (ESM, NodeNext), `@modelcontextprotocol/sdk`, `google-auth-library`, `zod`, `vitest`, `tsx` (for scripts). Direct `fetch` to the Ad Manager REST API v1 — no `googleapis` meta-package, which keeps the npx download lean.

## Conventions used throughout this plan

- **Imports use `.js` extensions** even for `.ts` source files (NodeNext ESM resolution).
- **Every file is ≤ ~150 lines.** If you find yourself writing more, extract a helper.
- **Tests live alongside in `tests/`**, mirroring `src/` paths (e.g., `src/dates.ts` ↔ `tests/dates.test.ts`).
- **Fixtures, not mocks of HTTP**: the GAM client is mocked at the interface level. Fixtures are real-shaped data, not mock function calls.
- **One commit per task.** Commit message format: `<type>: <subject>` (e.g., `feat: add date resolver`, `test: add fixtures for revenue_summary`).

## Known v1 simplifications (deferred to v1.x)

These are honest deviations from the spec that reduce v1 scope without changing user-visible behavior in any meaningful way. Documented here so the engineer doesn't think they're missing something:

- **Structured logger.** The spec describes `GAM_LOG_LEVEL`-controlled JSON-lines logging. v1 just writes to stderr at info-level always; the `GAM_LOG_LEVEL` env var is read but does not yet filter. Adding a real logger (e.g., `pino`) is a small follow-up. The README documents `GAM_LOG_LEVEL` as "reserved for future use."
- **Auto-resolve names in entity filters.** The spec locks in name↔ID auto-resolve where tools expose entity filters. In v1 the opinionated tools don't expose entity filters that benefit from name input (`pacing_status` takes numeric `line_item_ids`/`order_ids`; nothing else takes entity refs). The `lookup` tool is the explicit two-step path. When v1.x adds tools like `revenue_for_advertiser(name)`, port the auto-resolve helper into the report-tool factory.
- **Test fixtures inline rather than in `tests/fixtures/*.csv.gz` files.** Each tool test builds its CSV inline with `gzipSync(Buffer.from(...))`. Equivalent test value, less file ceremony. Move to disk fixtures if/when a single test needs a multi-thousand-row CSV.

```ts
export type RelativeRange =
  | 'today'
  | 'yesterday'
  | 'last_7_days'
  | 'last_30_days'
  | 'last_week'
  | 'last_full_month'
  | 'month_to_date'
  | 'quarter_to_date'
  | 'last_quarter'
  | 'year_to_date';

export type DateRange =
  | { start: string; end: string }
  | { relative: RelativeRange };

export type ResolvedRange = { start: string; end: string };

export function resolveDateRange(
  range: DateRange,
  timezone: string,
  now: Date = new Date(),
): ResolvedRange {
  const today = ymdInTz(now, timezone);
  const yesterday = addDays(today, -1);

  if ('start' in range) {
    if (range.start > range.end) {
      throw new Error(`INVALID_DATE_RANGE: start ${range.start} is after end ${range.end}`);
    }
    if (range.end > yesterday) {
      throw new Error(
        `INVALID_DATE_RANGE: end ${range.end} is after yesterday ${yesterday} in ${timezone}`,
      );
    }
    return { start: range.start, end: range.end };
  }

  switch (range.relative) {
    case 'today':       return { start: today, end: today };
    case 'yesterday':   return { start: yesterday, end: yesterday };
    case 'last_7_days': return { start: addDays(yesterday, -6), end: yesterday };
    case 'last_30_days':return { start: addDays(yesterday, -29), end: yesterday };
    case 'last_week': {
      // Mon-Sun of the previous full week
      const dow = dayOfWeekInTz(now, timezone); // 0=Sun..6=Sat
      const daysSinceLastSunday = dow === 0 ? 7 : dow;
      const lastSunday = addDays(today, -daysSinceLastSunday);
      const lastMonday = addDays(lastSunday, -6);
      return { start: lastMonday, end: lastSunday };
    }
    case 'last_full_month': {
      const [y, m] = today.split('-').map(Number);
      const firstOfThisMonth = `${y}-${String(m).padStart(2, '0')}-01`;
      const lastDay = addDays(firstOfThisMonth, -1);
      const [py, pm] = lastDay.split('-').map(Number);
      const firstOfPrev = `${py}-${String(pm).padStart(2, '0')}-01`;
      return { start: firstOfPrev, end: lastDay };
    }
    case 'month_to_date': {
      const [y, m] = today.split('-').map(Number);
      return { start: `${y}-${String(m).padStart(2, '0')}-01`, end: yesterday };
    }
    case 'quarter_to_date': {
      const [y, m] = today.split('-').map(Number);
      const qStartMonth = m - ((m - 1) % 3);
      return {
        start: `${y}-${String(qStartMonth).padStart(2, '0')}-01`,
        end: yesterday,
      };
    }
    case 'last_quarter': {
      const [y, m] = today.split('-').map(Number);
      const thisQStart = m - ((m - 1) % 3);
      let lastQStartMonth = thisQStart - 3;
      let lastQYear = y;
      if (lastQStartMonth <= 0) {
        lastQStartMonth += 12;
        lastQYear -= 1;
      }
      const start = `${lastQYear}-${String(lastQStartMonth).padStart(2, '0')}-01`;
      const lastQEndDay = addDays(`${y}-${String(thisQStart).padStart(2, '0')}-01`, -1);
      return { start, end: lastQEndDay };
    }
    case 'year_to_date': {
      const [y] = today.split('-').map(Number);
      return { start: `${y}-01-01`, end: yesterday };
    }
  }
}

function ymdInTz(d: Date, tz: string): string {
  // Intl is the only stdlib path to a ZonedDateTime in Node.
  const fmt = new Intl.DateTimeFormat('en-CA', {
    timeZone: tz,
    year: 'numeric',
    month: '2-digit',
    day: '2-digit',
  });
  // en-CA outputs YYYY-MM-DD already.
  return fmt.format(d);
}

function dayOfWeekInTz(d: Date, tz: string): number {
  const fmt = new Intl.DateTimeFormat('en-US', { timeZone: tz, weekday: 'short' });
  const wd = fmt.format(d);
  return ['Sun', 'Mon', 'Tue', 'Wed', 'Thu', 'Fri', 'Sat'].indexOf(wd);
}

function addDays(ymd: string, days: number): string {
  const [y, m, d] = ymd.split('-').map(Number);
  const date = new Date(Date.UTC(y, m - 1, d));
  date.setUTCDate(date.getUTCDate() + days);
  const yy = date.getUTCFullYear();
  const mm = String(date.getUTCMonth() + 1).padStart(2, '0');
  const dd = String(date.getUTCDate()).padStart(2, '0');
  return `${yy}-${mm}-${dd}`;
}
```

```ts
export type GamErrorCode =
  | 'INVALID_DATE_RANGE'
  | 'INVALID_INPUT'
  | 'AUTH_FAILED'
  | 'QUOTA_EXCEEDED'
  | 'REPORT_FAILED'
  | 'REPORT_TIMEOUT'
  | 'ENTITY_NOT_FOUND'
  | 'AMBIGUOUS_NAME'
  | 'UNSUPPORTED_DIMENSION_COMBO'
  | 'INTERNAL_ERROR';

export type GamErrorEnvelope = {
  error: {
    code: GamErrorCode;
    message: string;
    hint: string;
    details: Record<string, unknown>;
  };
};

type Renderer = (details: Record<string, unknown>) => { message: string; hint: string };

const CATALOG: Record<GamErrorCode, Renderer> = {
  INVALID_DATE_RANGE: (d) => ({
    message: `Invalid date range: ${d.reason ?? 'unknown reason'}.`,
    hint: 'Use YYYY-MM-DD strings, ensure start ≤ end, and pick an end date no later than yesterday in the network timezone.',
  }),
  INVALID_INPUT: (d) => ({
    message: `Invalid input: ${d.reason ?? 'see details'}.`,
    hint: String(d.hint ?? 'Check the tool input schema and try again.'),
  }),
  AUTH_FAILED: () => ({
    message: 'Failed to authenticate with the Google Ad Manager API.',
    hint: 'Check that GAM_SERVICE_ACCOUNT_KEY_FILE points to a readable service-account JSON and that the account has Ad Manager API access.',
  }),
  QUOTA_EXCEEDED: (d) => ({
    message: 'GAM API rate-limited this request.',
    hint: d.retry_after_seconds
      ? `Retry after ${d.retry_after_seconds}s.`
      : 'Wait and retry; consider narrowing the date range.',
  }),
  REPORT_FAILED: (d) => ({
    message: `Report job failed: ${d.reason ?? 'unknown'}.`,
    hint: 'Verify dimension/metric combinations are supported (call describe_schema) and filters reference real entities.',
  }),
  REPORT_TIMEOUT: (d) => ({
    message: `Report did not finish within ${d.timeout_ms ?? 300000}ms.`,
    hint: 'Narrow the date range, reduce dimensions, or set GAM_REPORT_TIMEOUT_MS higher.',
  }),
  ENTITY_NOT_FOUND: (d) => ({
    message: `No ${d.entity_type} matched ${JSON.stringify(d.query)}.`,
    hint: `Try lookup with entity_type: '${d.entity_type}' to see candidate matches.`,
  }),
  AMBIGUOUS_NAME: (d) => ({
    message: `Multiple ${d.entity_type}s matched ${JSON.stringify(d.query)}.`,
    hint: 'Pick a specific candidate from details.candidates and re-run with its numeric ID.',
  }),
  UNSUPPORTED_DIMENSION_COMBO: (d) => ({
    message: `Dimension combination not supported: ${d.dims}.`,
    hint: 'Call describe_schema to see allowed combinations.',
  }),
  INTERNAL_ERROR: (d) => ({
    message: `Internal error: ${d.reason ?? 'see logs'}.`,
    hint: 'Re-run; if it persists, check stderr logs for the correlation ID.',
  }),
};

export function gamError(
  code: GamErrorCode,
  details: Record<string, unknown> = {},
): GamErrorEnvelope {
  const { message, hint } = CATALOG[code](details);
  return { error: { code, message, hint, details } };
}

export function isGamError(x: unknown): x is GamErrorEnvelope {
  return (
    typeof x === 'object' &&
    x !== null &&
    'error' in x &&
    typeof (x as GamErrorEnvelope).error?.code === 'string'
  );
}
```

```ts
    schema?: SchemaField[],
  ) => OutputEnvelope;
  cleanup: () => void;
  tempDir: string;
};

export function createOutputManager(opts: {
  tempDir: string;
  inlineThreshold: number;
  previewLimit?: number;
}): OutputManager {
  if (!existsSync(opts.tempDir)) mkdirSync(opts.tempDir, { recursive: true });
  const previewLimit = opts.previewLimit ?? 50;

  return {
    tempDir: opts.tempDir,

    async fromCsvGzFile(path, summary, warnings) {
      const { header, rows } = await readCsvGz(path);
      const schema: SchemaField[] = header.map((name) => ({ name, type: 'string' }));
      if (rows.length <= opts.inlineThreshold) {
        try { unlinkSync(path); } catch { /* ignore */ }
        return { summary, row_count: rows.length, schema, rows, ...(warnings && { warnings }) };
      }
      return {
        summary,
        row_count: rows.length,
        schema,
        file_path: path,
        preview_rows: rows.slice(0, previewLimit),
        ...(warnings && { warnings }),
      };
    },

    fromInlineRows(rows, summary, schema) {
      const inferred = schema ?? (rows[0]
        ? Object.keys(rows[0]).map((name) => ({ name, type: 'string' as const }))
        : []);
      return { summary, row_count: rows.length, schema: inferred, rows };
    },

    cleanup() {
      rmSync(opts.tempDir, { recursive: true, force: true });
    },
  };
}

async function readCsvGz(path: string): Promise<{ header: string[]; rows: Record<string, string>[] }> {
  const stream = createReadStream(path).pipe(createGunzip());
  const rl = createInterface({ input: stream, crlfDelay: Infinity });
  const rows: Record<string, string>[] = [];
  let header: string[] = [];
  let lineNo = 0;
  for await (const line of rl) {
    if (lineNo === 0) {
      header = parseCsvLine(line);
    } else if (line.length > 0) {
      const fields = parseCsvLine(line);
      const row: Record<string, string> = {};
      header.forEach((h, i) => { row[h] = fields[i] ?? ''; });
      rows.push(row);
    }
    lineNo++;
  }
  return { header, rows };
}

function parseCsvLine(line: string): string[] {
  // Minimal RFC 4180 parser: handles quoted fields with embedded commas + escaped quotes.
  const result: string[] = [];
  let cur = '';
  let inQuotes = false;
  for (let i = 0; i < line.length; i++) {
    const ch = line[i];
    if (inQuotes) {
      if (ch === '"') {
        if (line[i + 1] === '"') { cur += '"'; i++; }
        else { inQuotes = false; }
      } else {
        cur += ch;
      }
    } else if (ch === '"') {
      inQuotes = true;
    } else if (ch === ',') {
      result.push(cur);
      cur = '';
    } else {
      cur += ch;
    }
  }
  result.push(cur);
  return result;
}
```

```ts
export type EntityType =
  | 'advertiser' | 'order' | 'line_item' | 'ad_unit' | 'creative' | 'placement' | 'company';

export type Entity = { id: number; name: string; [k: string]: unknown };

export type ReportQuery = {
  dimensions: string[];
  metrics: string[];
  filters?: { field: string; op: '=' | 'IN' | '!='; value: number | string | (number | string)[] }[];
};

export type ReportOperation = { operation_name: string };

export type OperationStatus =
  | { state: 'pending' }
  | { state: 'running' }
  | { state: 'done'; download_url: string }
  | { state: 'failed'; reason: string };

export type DateRange = { start: string; end: string };

export type GAMClient = {
  listEntities: (q: { entity_type: EntityType; query?: string; ids?: number[] }) => Promise<Entity[]>;
  createReport: (query: ReportQuery, dateRange: DateRange) => Promise<ReportOperation>;
  pollOperation: (operation_name: string) => Promise<OperationStatus>;
  downloadReport: (downloadUrl: string, destPath: string) => Promise<string>;
};

// ------------------------- in-memory mock for tests ------------------------

export type ReportFixture = {
  query: ReportQuery;
  dateRange?: DateRange;
  csvGz: Buffer;
};

export type MockState = {
  entities?: Partial<Record<EntityType, Entity[]>>;
  reports?: ReportFixture[];
};

export function createMockGamClient(state: MockState = {}): GAMClient {
  const reports = state.reports ?? [];
  const operations = new Map<string, { fixture: ReportFixture; polledOnce: boolean }>();
  let counter = 0;

  const matchFixture = (q: ReportQuery): ReportFixture | undefined =>
    reports.find((r) =>
      sameDimsMetrics(r.query, q),
    );

  return {
    async listEntities({ entity_type, query, ids }) {
      const all = state.entities?.[entity_type] ?? [];
      if (ids?.length) return all.filter((e) => ids.includes(e.id));
      if (!query) return all;
      const q = query.toLowerCase();
      return all.filter((e) => e.name.toLowerCase().includes(q));
    },
    async createReport(query) {
      const fixture = matchFixture(query);
      if (!fixture) {
        throw new Error(
          `mock: no report fixture matches query dimensions=${query.dimensions.join(',')} metrics=${query.metrics.join(',')}`,
        );
      }
      const name = `operations/${++counter}`;
      operations.set(name, { fixture, polledOnce: false });
      return { operation_name: name };
    },
    async pollOperation(name) {
      const op = operations.get(name);
      if (!op) return { state: 'failed', reason: 'unknown operation' };
      if (!op.polledOnce) {
        op.polledOnce = true;
        return { state: 'running' };
      }
      return { state: 'done', download_url: `mock://${name}` };
    },
    async downloadReport(downloadUrl, destPath) {
      const name = downloadUrl.replace(/^mock:\/\//, '');
      const op = operations.get(name);
      if (!op) throw new Error(`mock: unknown download ${downloadUrl}`);
      writeFileSync(destPath, op.fixture.csvGz);
      return destPath;
    },
  };
}

function sameDimsMetrics(a: ReportQuery, b: ReportQuery): boolean {
  const sa = new Set(a.dimensions); const sb = new Set(b.dimensions);
  const ma = new Set(a.metrics);    const mb = new Set(b.metrics);
  return setEq(sa, sb) && setEq(ma, mb);
}
function setEq<T>(a: Set<T>, b: Set<T>): boolean {
  if (a.size !== b.size) return false;
  for (const x of a) if (!b.has(x)) return false;
  return true;
}
```

```ts
import { gamError } from './errors.js';

export type GoogleAuthLike = {
  getAccessToken: () => Promise<string | null | undefined>;
};

export function createGoogleAuth(keyFile: string): GoogleAuthLike {
  const auth = new GoogleAuth({
    keyFile,
    scopes: ['https://www.googleapis.com/auth/admanager'],
  });
  return {
    async getAccessToken() {
      const client = await auth.getClient();
      const t = await client.getAccessToken();
      return t.token ?? null;
    },
  };
}

export function createAuthFetch(
  auth: GoogleAuthLike,
  baseFetch: typeof fetch = fetch,
): typeof fetch {
  return (async (input: RequestInfo | URL, init: RequestInit = {}) => {
    const token = await auth.getAccessToken();
    if (!token) throw new Error(JSON.stringify(gamError('AUTH_FAILED')));
    const headers = new Headers(init.headers);
    headers.set('Authorization', `Bearer ${token}`);
    return baseFetch(input, { ...init, headers });
  }) as typeof fetch;
}
```

```ts
import { z, type ZodTypeAny } from 'zod';
import { join } from 'node:path';
import { gamError } from './errors.js';
import type { GAMClient, ReportQuery, DateRange } from './gam-client.js';
import type { OutputManager, OutputEnvelope } from './output.js';

export type ToolContext = {
  client: GAMClient;
  output: OutputManager;
  timezone: string;
  now?: Date;
  reportTimeoutMs?: number;
};

export type ToolDefinition<I extends ZodTypeAny> = {
  name: string;
  description: string;
  input: I;
  handler: (input: z.infer<I>, ctx: ToolContext) => Promise<OutputEnvelope | { error: unknown }>;
};

export type ReportToolConfig<I extends ZodTypeAny> = {
  name: string;
  description: string;
  input: I;
  /** Convert validated input to the GAM ReportQuery (dimensions/metrics/filters). */
  buildQuery: (input: z.infer<I>) => ReportQuery;
  /** Convert validated input to a date range. Defaults to using `input.date_range`. */
  buildDateRange?: (input: z.infer<I>) => DateRange;
  /** Build the human-readable summary string returned in the envelope. */
  summary: (input: z.infer<I>) => string;
};

export function buildReportTool<I extends ZodTypeAny>(
  cfg: ReportToolConfig<I>,
): ToolDefinition<I> {
  return {
    name: cfg.name,
    description: cfg.description,
    input: cfg.input,
    async handler(input, ctx) {
      const query = cfg.buildQuery(input);
      const dateRange = (cfg.buildDateRange?.(input) ??
        (input as { date_range: DateRange }).date_range);

      const op = await ctx.client.createReport(query, dateRange);
      const status = await pollUntilDone(
        ctx.client,
        op.operation_name,
        ctx.reportTimeoutMs ?? 300_000,
      );
      if ('error' in status) return status;

      const dest = join(ctx.output.tempDir, `${op.operation_name.replace(/[^\w]/g, '_')}.csv.gz`);
      await ctx.client.downloadReport(status.download_url, dest);
      return ctx.output.fromCsvGzFile(dest, cfg.summary(input));
    },
  };
}

async function pollUntilDone(
  client: GAMClient,
  name: string,
  timeoutMs: number,
): Promise<{ download_url: string } | { error: unknown }> {
  const start = Date.now();
  let delay = 2000;
  while (Date.now() - start < timeoutMs) {
    const s = await client.pollOperation(name);
    if (s.state === 'done') return { download_url: s.download_url };
    if (s.state === 'failed') return gamError('REPORT_FAILED', { reason: s.reason });
    await sleep(delay);
    delay = Math.min(delay * 1.5, 15_000);
  }
  return gamError('REPORT_TIMEOUT', { timeout_ms: timeoutMs });
}

function sleep(ms: number): Promise<void> {
  return new Promise((r) => setTimeout(r, ms));
}
```

```ts
import { z } from 'zod';
import { gamError } from '../errors.js';
import type { ToolDefinition, ToolContext } from '../report-tool-builder.js';

const ENTITY_TYPES = [
  'advertiser', 'order', 'line_item', 'ad_unit', 'creative', 'placement', 'company',
] as const;

const inputSchema = z.object({
  entity_type: z.enum(ENTITY_TYPES),
  query: z.string().min(1).optional(),
  ids: z.array(z.number().int().positive()).optional(),
  limit: z.number().int().min(1).max(200).default(50),
}).refine((v) => v.query !== undefined || (v.ids && v.ids.length > 0), {
  message: 'Provide either query or ids',
});

export const lookupTool: ToolDefinition<typeof inputSchema> = {
  name: 'lookup',
  description:
    'Resolve names ↔ IDs for GAM entities (advertiser, order, line_item, ad_unit, creative, placement, company). Supports substring search by query, or exact lookup by ids.',
  input: inputSchema,
  async handler(input, ctx: ToolContext) {
    const matches = await ctx.client.listEntities({
      entity_type: input.entity_type,
      query: input.query,
      ids: input.ids,
    });
    if (matches.length === 0) {
      return gamError('ENTITY_NOT_FOUND', {
        entity_type: input.entity_type,
        query: input.query ?? input.ids,
      });
    }
    const trimmed = matches.slice(0, input.limit);
    const rows = trimmed.map((e) => ({ id: String(e.id), name: e.name }));
    return ctx.output.fromInlineRows(
      rows,
      `${trimmed.length} ${input.entity_type}(s) matching ${JSON.stringify(input.query ?? input.ids)}`,
    );
  },
};
```

```ts
import { z } from 'zod';
import { gamError } from '../errors.js';
import { resolveDateRange } from '../dates.js';
import { validateCombo } from '../schema.js';
import { join } from 'node:path';
import type { ToolDefinition } from '../report-tool-builder.js';

const RELATIVE = z.enum([
  'today', 'yesterday', 'last_7_days', 'last_30_days', 'last_week',
  'last_full_month', 'month_to_date', 'quarter_to_date', 'last_quarter', 'year_to_date',
]);

const dateRangeSchema = z.union([
  z.object({ start: z.string(), end: z.string() }),
  z.object({ relative: RELATIVE }),
]);

const filterSchema = z.object({
  field: z.string(),
  op: z.enum(['=', 'IN', '!=']).default('='),
  value: z.union([z.string(), z.number(), z.array(z.union([z.string(), z.number()]))]),
});

const inputSchema = z.object({
  dimensions: z.array(z.string()).min(1).max(10),
  metrics: z.array(z.string()).min(1).max(20),
  date_range: dateRangeSchema,
  filters: z.array(filterSchema).optional(),
});

export const runReportTool: ToolDefinition<typeof inputSchema> = {
  name: 'run_report',
  description:
    'Run an arbitrary GAM report. Pick dimensions and metrics from describe_schema. Date range accepts absolute {start,end} or {relative: enum}. Returns standard envelope (inline if small, file path if large).',
  input: inputSchema,
  async handler(input, ctx) {
    const comboError = validateCombo({ dimensions: input.dimensions, metrics: input.metrics });
    if (comboError) {
      return gamError('INVALID_INPUT', { reason: comboError, hint: 'Call describe_schema for valid names.' });
    }

    let dateRange;
    try {
      dateRange = resolveDateRange(input.date_range, ctx.timezone, ctx.now);
    } catch (e) {
      const msg = e instanceof Error ? e.message : String(e);
      return gamError('INVALID_DATE_RANGE', { reason: msg });
    }

    try {
      const op = await ctx.client.createReport(
        { dimensions: input.dimensions, metrics: input.metrics, filters: input.filters },
        dateRange,
      );
      const status = await pollUntilDone(ctx.client, op.operation_name, ctx.reportTimeoutMs ?? 300_000);
      if ('error' in status) return status;
      const dest = join(ctx.output.tempDir, `${op.operation_name.replace(/[^\w]/g, '_')}.csv.gz`);
      await ctx.client.downloadReport(status.download_url, dest);
      return ctx.output.fromCsvGzFile(
        dest,
        `Report: dims=[${input.dimensions.join(',')}] metrics=[${input.metrics.join(',')}] ${dateRange.start}..${dateRange.end}`,
      );
    } catch (e) {
      return gamError('INTERNAL_ERROR', { reason: e instanceof Error ? e.message : String(e) });
    }
  },
};

async function pollUntilDone(client: GAMClient, name: string, timeoutMs: number) {
  const start = Date.now();
  let delay = 2000;
  while (Date.now() - start < timeoutMs) {
    const s = await client.pollOperation(name);
    if (s.state === 'done') return { download_url: s.download_url };
    if (s.state === 'failed') return gamError('REPORT_FAILED', { reason: s.reason });
    await new Promise((r) => setTimeout(r, delay));
    delay = Math.min(delay * 1.5, 15_000);
  }
  return gamError('REPORT_TIMEOUT', { timeout_ms: timeoutMs });
}
```

```ts
import { z } from 'zod';
import { join } from 'node:path';
import { gamError } from '../errors.js';
import { resolveDateRange } from '../dates.js';
import type { ToolDefinition, ToolContext } from '../report-tool-builder.js';
import type { ReportQuery } from '../gam-client.js';

const inputSchema = z.object({
  line_item_ids: z.array(z.number().int().positive()).optional(),
  order_ids: z.array(z.number().int().positive()).optional(),
});

export const pacingStatusTool: ToolDefinition<typeof inputSchema> = {
  name: 'pacing_status',
  description:
    'Pacing status (delivered vs. expected) for currently-flighting line items, month-to-date in the network timezone. Returns line_item_progress (0..1+) along with delivered impressions and goal quantity. Optional filter by line_item_ids or order_ids.',
  input: inputSchema,
  async handler(input, ctx: ToolContext) {
    const dateRange = resolveDateRange({ relative: 'month_to_date' }, ctx.timezone, ctx.now);
    const query: ReportQuery = {
      dimensions: ['LINE_ITEM_NAME', 'LINE_ITEM_ID'],
      metrics: [
        'LINE_ITEM_PROGRESS',
        'LINE_ITEM_LIFETIME_IMPRESSIONS_DELIVERED',
        'LINE_ITEM_GOAL_QUANTITY',
      ],
      filters: [
        ...(input.line_item_ids?.length
          ? [{ field: 'LINE_ITEM_ID', op: 'IN' as const, value: input.line_item_ids }]
          : []),
        ...(input.order_ids?.length
          ? [{ field: 'ORDER_ID', op: 'IN' as const, value: input.order_ids }]
          : []),
      ],
    };

    const op = await ctx.client.createReport(query, dateRange);
    const timeout = ctx.reportTimeoutMs ?? 300_000;
    const start = Date.now();
    let delay = 2000;
    while (Date.now() - start < timeout) {
      const s = await ctx.client.pollOperation(op.operation_name);
      if (s.state === 'done') {
        const dest = join(ctx.output.tempDir, `${op.operation_name.replace(/[^\w]/g, '_')}.csv.gz`);
        await ctx.client.downloadReport(s.download_url, dest);
        return ctx.output.fromCsvGzFile(dest, 'Pacing status (current month)');
      }
      if (s.state === 'failed') return gamError('REPORT_FAILED', { reason: s.reason });
      await new Promise((r) => setTimeout(r, delay));
      delay = Math.min(delay * 1.5, 15_000);
    }
    return gamError('REPORT_TIMEOUT', { timeout_ms: timeout });
  },
};
```

```ts
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';
import {
  CallToolRequestSchema,
  ListToolsRequestSchema,
} from '@modelcontextprotocol/sdk/types.js';
import { ALL_TOOLS } from './tools/index.js';
import type { ToolContext } from './report-tool-builder.js';
import { gamError } from './errors.js';
import { z } from 'zod';

export function listToolNames(): string[] {
  return ALL_TOOLS.map((t) => t.name);
}

export function installStdoutGuard(): () => void {
  const original = process.stdout.write.bind(process.stdout);
  process.stdout.write = ((chunk: any, ...rest: any[]) => {
    const s = typeof chunk === 'string' ? chunk : Buffer.from(chunk).toString();
    // MCP frames are newline-delimited JSON-RPC over stdio. Let those through.
    // Everything else (stray console.log from a dependency, etc.) goes to stderr.
    if (s.startsWith('{"jsonrpc"') || s.startsWith('Content-Length:')) {
      return original(chunk, ...rest);
    }
    process.stderr.write(`[stdout-guard] ${s}`);
    return true;
  }) as typeof process.stdout.write;
  return () => { process.stdout.write = original; };
}

export async function startMcpServer(ctx: ToolContext): Promise<void> {
  const server = new Server(
    { name: 'gam-mcp', version: '0.1.0' },
    { capabilities: { tools: {} } },
  );

  server.setRequestHandler(ListToolsRequestSchema, async () => ({
    tools: ALL_TOOLS.map((t) => ({
      name: t.name,
      description: t.description,
      inputSchema: zodToJsonSchema(t.input),
    })),
  }));

  server.setRequestHandler(CallToolRequestSchema, async (req) => {
    const tool = ALL_TOOLS.find((t) => t.name === req.params.name);
    if (!tool) {
      return {
        content: [{ type: 'text', text: JSON.stringify(gamError('INVALID_INPUT', { reason: `Unknown tool ${req.params.name}` })) }],
        isError: true,
      };
    }
    const parsed = tool.input.safeParse(req.params.arguments ?? {});
    if (!parsed.success) {
      return {
        content: [{ type: 'text', text: JSON.stringify(gamError('INVALID_INPUT', { reason: parsed.error.message })) }],
        isError: true,
      };
    }
    try {
      const result = await tool.handler(parsed.data, ctx);
      return { content: [{ type: 'text', text: JSON.stringify(result) }] };
    } catch (e) {
      return {
        content: [{ type: 'text', text: JSON.stringify(gamError('INTERNAL_ERROR', { reason: e instanceof Error ? e.message : String(e) })) }],
        isError: true,
      };
    }
  });

  const transport = new StdioServerTransport();
  await server.connect(transport);
}

// Minimal zod → JSON Schema. zod has many third-party converters; for v1 we
// emit a permissive schema that lets the LLM at least see field names.
function zodToJsonSchema(schema: z.ZodTypeAny): unknown {
  if (schema instanceof z.ZodObject) {
    const shape = (schema as z.ZodObject<any>).shape;
    const properties: Record<string, unknown> = {};
    const required: string[] = [];
    for (const key of Object.keys(shape)) {
      const sub = shape[key];
      properties[key] = zodToJsonSchema(sub);
      if (!sub.isOptional()) required.push(key);
    }
    return { type: 'object', properties, required };
  }
  if (schema instanceof z.ZodString) return { type: 'string' };
  if (schema instanceof z.ZodNumber) return { type: 'number' };
  if (schema instanceof z.ZodBoolean) return { type: 'boolean' };
  if (schema instanceof z.ZodArray) return { type: 'array', items: zodToJsonSchema((schema as z.ZodArray<any>).element) };
  if (schema instanceof z.ZodEnum) return { type: 'string', enum: (schema as z.ZodEnum<any>).options };
  if (schema instanceof z.ZodOptional) return zodToJsonSchema((schema as z.ZodOptional<any>).unwrap());
  if (schema instanceof z.ZodUnion) return { anyOf: (schema as z.ZodUnion<any>).options.map(zodToJsonSchema) };
  if (schema instanceof z.ZodDefault) return zodToJsonSchema((schema as any)._def.innerType);
  return {};
}
```

```ts
import { writeFileSync } from 'node:fs';
import type {
  GAMClient,
  EntityType,
  ReportQuery,
  ReportOperation,
  OperationStatus,
  Entity,
  DateRange,
} from './gam-client.js';
import { gamError } from './errors.js';

const BASE = 'https://admanager.googleapis.com/v1';

const ENTITY_PATH: Record<EntityType, { collection: string; idField: string }> = {
  advertiser: { collection: 'companies',  idField: 'companyId' },
  company:    { collection: 'companies',  idField: 'companyId' },
  order:      { collection: 'orders',     idField: 'orderId' },
  line_item:  { collection: 'lineItems',  idField: 'lineItemId' },
  ad_unit:    { collection: 'adUnits',    idField: 'adUnitId' },
  creative:   { collection: 'creatives',  idField: 'creativeId' },
  placement:  { collection: 'placements', idField: 'placementId' },
};

export function createRestGamClient(opts: {
  networkCode: string;
  fetchImpl?: typeof fetch;
}): GAMClient {
  const fetchImpl = opts.fetchImpl ?? fetch;
  const networkPath = `${BASE}/networks/${opts.networkCode}`;

  return {
    async listEntities({ entity_type, query, ids }) {
      const meta = ENTITY_PATH[entity_type];
      const params = new URLSearchParams();
      params.set('pageSize', '200');
      if (query) params.set('filter', `name:CONTAINS:${JSON.stringify(query)}`);
      if (ids?.length) params.set('filter', ids.map((i) => `${meta.idField}=${i}`).join(' OR '));
      const url = `${networkPath}/${meta.collection}?${params}`;
      const res = await fetchImpl(url);
      if (!res.ok) throw new Error(`listEntities ${res.status}: ${await res.text()}`);
      const json = await res.json() as Record<string, unknown>;
      const list = (json[meta.collection] as any[] | undefined) ?? [];
      return list.map((e): Entity => ({
        id: Number(e[meta.idField]),
        name: String(e.name ?? e.displayName ?? ''),
        ...e,
      }));
    },

    async createReport(query: ReportQuery, dateRange: DateRange): Promise<ReportOperation> {
      const body = {
        report: {
          dimensions: query.dimensions,
          metrics: query.metrics,
          dateRange: { startDate: dateRange.start, endDate: dateRange.end },
          ...(query.filters?.length && { filter: pqlFromFilters(query.filters) }),
        },
      };
      const res = await fetchImpl(`${networkPath}/reports:runReport`, {
        method: 'POST',
        headers: { 'content-type': 'application/json' },
        body: JSON.stringify(body),
      });
      if (!res.ok) throw new Error(`createReport ${res.status}: ${await res.text()}`);
      const op = await res.json() as { name: string };
      return { operation_name: op.name };
    },

    async pollOperation(operation_name: string): Promise<OperationStatus> {
      const res = await fetchImpl(`${BASE}/${operation_name}`);
      if (res.status === 429) return { state: 'failed', reason: 'QUOTA_EXCEEDED' };
      if (!res.ok) throw new Error(`pollOperation ${res.status}: ${await res.text()}`);
      const op = await res.json() as { done?: boolean; error?: { message: string }; response?: { downloadUrl?: string } };
      if (!op.done) return { state: 'running' };
      if (op.error) return { state: 'failed', reason: op.error.message };
      const url = op.response?.downloadUrl;
      if (!url) return { state: 'failed', reason: 'response missing downloadUrl' };
      return { state: 'done', download_url: url };
    },

    async downloadReport(downloadUrl: string, destPath: string): Promise<string> {
      const res = await fetchImpl(downloadUrl);
      if (!res.ok) throw new Error(`downloadReport ${res.status}: ${await res.text()}`);
      const buf = Buffer.from(await res.arrayBuffer());
      writeFileSync(destPath, buf);
      return destPath;
    },
  };
}

function pqlFromFilters(filters: NonNullable<ReportQuery['filters']>): string {
  return filters.map((f) => {
    const v = Array.isArray(f.value)
      ? `(${f.value.map((x) => typeof x === 'string' ? `'${x}'` : String(x)).join(',')})`
      : typeof f.value === 'string' ? `'${f.value}'` : String(f.value);
    return `${f.field} ${f.op} ${v}`;
  }).join(' AND ');
}
```

```ts
import { writeFileSync } from 'node:fs';
import { createGoogleAuth, createAuthFetch } from '../src/auth.js';

async function main(): Promise<void> {
  const networkCode = process.env.GAM_NETWORK_CODE;
  const keyFile = process.env.GAM_SERVICE_ACCOUNT_KEY_FILE;
  if (!networkCode || !keyFile) {
    process.stderr.write('Set GAM_NETWORK_CODE and GAM_SERVICE_ACCOUNT_KEY_FILE.\n');
    process.exit(2);
  }

  const fetchImpl = createAuthFetch(createGoogleAuth(keyFile));
  const url = `https://admanager.googleapis.com/v1/networks/${networkCode}/reports:fetchReportMetadata`;
  const res = await fetchImpl(url);
  if (!res.ok) {
    process.stderr.write(`fetchReportMetadata ${res.status}: ${await res.text()}\n`);
    process.exit(1);
  }
  const meta = await res.json() as {
    dimensions?: { name: string; type: string; description?: string }[];
    metrics?: { name: string; type: string; description?: string }[];
  };

  const dims = (meta.dimensions ?? []).map((d) => ({
    name: d.name,
    type: mapDimensionType(d.type),
    description: d.description ?? '',
  }));
  const metrics = (meta.metrics ?? []).map((m) => ({
    name: m.name,
    type: mapMetricType(m.type),
    description: m.description ?? '',
  }));

  const fileBody =
    `// AUTO-GENERATED by scripts/refresh-schema.ts on ${new Date().toISOString()}\n` +
    `// Network: ${networkCode}\n\n` +
    `export type DimensionDef = { name: string; type: 'string' | 'number' | 'date'; description: string };\n` +
    `export type MetricDef = { name: string; type: 'number' | 'currency' | 'rate'; description: string };\n\n` +
    `export const GAM_SCHEMA: { dimensions: DimensionDef[]; metrics: MetricDef[] } = {\n` +
    `  dimensions: ${JSON.stringify(dims, null, 2)},\n` +
    `  metrics: ${JSON.stringify(metrics, null, 2)},\n` +
    `};\n\n` +
    `const DIMS = new Set(GAM_SCHEMA.dimensions.map((d) => d.name));\n` +
    `const METRICS = new Set(GAM_SCHEMA.metrics.map((m) => m.name));\n\n` +
    `export function isValidDimension(name: string): boolean { return DIMS.has(name); }\n` +
    `export function isValidMetric(name: string): boolean { return METRICS.has(name); }\n\n` +
    `export function validateCombo(q: { dimensions: string[]; metrics: string[] }): string | null {\n` +
    `  for (const d of q.dimensions) if (!isValidDimension(d)) return \`Unknown dimension: \${d}\`;\n` +
    `  for (const m of q.metrics) if (!isValidMetric(m)) return \`Unknown metric: \${m}\`;\n` +
    `  return null;\n` +
    `}\n`;

  writeFileSync('src/schema.ts', fileBody);
  process.stderr.write(`wrote src/schema.ts: ${dims.length} dims, ${metrics.length} metrics\n`);
}

function mapDimensionType(t: string): 'string' | 'number' | 'date' {
  if (/DATE|WEEK|MONTH|HOUR/.test(t)) return 'date';
  if (/INT|NUMBER|ID/.test(t)) return 'number';
  return 'string';
}
function mapMetricType(t: string): 'number' | 'currency' | 'rate' {
  if (/CURRENCY|REVENUE|COST/.test(t)) return 'currency';
  if (/RATE|RATIO|CTR/.test(t)) return 'rate';
  return 'number';
}

main().catch((e) => { process.stderr.write(`refresh-schema: ${e instanceof Error ? e.stack : String(e)}\n`); process.exit(1); });
```

Read-only MCP server for Google Ad Manager. Lets an LLM (e.g., Claude) analyze your network's revenue and inventory data through a small, opinionated tool surface plus a generic `run_report` escape hatch.

You don't. Add it to your MCP client config and let `npx` fetch it on first use.
