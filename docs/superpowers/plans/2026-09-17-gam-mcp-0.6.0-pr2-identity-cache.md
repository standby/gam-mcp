# gam-mcp 0.6.0 PR 2 — Reuse Reports, Check Identity, Cache Results

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Each call builds one report definition — in the network's own time zone and currency — and runs it under a name derived from its hash; the server proves its credential can read the network before serving; identical calls share one run, a run that outlives its caller is resumed rather than repeated, and repeated calls are answered from a cached *result reference* instead of a new report job. Later pages report facts the server holds, never the cursor's copies.

**Architecture:** `report-exec.ts` builds the `ReportDefinition` once and hands that object to `defineReport(definition)`; the clients no longer build definitions, and they name each report `gam-mcp <hash>` from the definition they are handed. `executeReport` and `executeReportRows` share one `firstPage()` step, which is where report reuse (`report-reuse.ts`), shared runs, the result cache (`cache.ts`, rewritten to hold `done`/`pending` references) and the silent re-run of an expired cached result live. A per-client memory (`lru.ts`) holds stored definitions and each result's first-page facts for `fetch_report_page`, and `report-warnings.ts` rebuilds caveats from a stored definition. `report-key.ts` holds the one hash function; `zones.ts` compares UTC offsets; `startup.ts` checks settings and calls `networks.get` before serving. POSTs are retried only on 429, and a suite-wide guard fails any test whose fake GAM receives another write.

**Tech Stack:** TypeScript (strict, ESM/nodenext), Node ≥ 22, zod 3, `@modelcontextprotocol/sdk` 1.x, google-auth-library 9, vitest 4.

**Spec:** `docs/superpowers/specs/2026-09-17-gam-mcp-0.6.0-design.md` (§2.2–§2.6; tests B1–B5, C1–C6, D1–D6, E1–E7, F1–F6, H7). Index: `docs/superpowers/plans/2026-09-17-gam-mcp-0.6.0-index.md`. Previous PR: `docs/superpowers/plans/2026-09-17-gam-mcp-0.6.0-pr1-report-path.md`. This plan also carries the ten binding follow-ups from PR 1's final review; the Self-Review Notes map each to a task.

### Task 1: One definition per call, handed to the client; one run-then-first-page step

Structural, with no change to what a tool returns. After this task `report-exec.ts` builds each `ReportDefinition` once (the one builder, which later tasks extend with `timeZoneSource`, `currencyCode` and — in PR 4 — `sorts`), hands that object to `defineReport(definition)`, and both `executeReport` and `executeReportRows` go through one `firstPage()` step. Every later behaviour in this PR (reuse, shared runs, cache hits, the silent re-run of an expired result) is written once, inside that step. `pageEnvelope` takes `cacheHit` and reads `sort` from the definition instead of hard-coding them.

```ts
import { gamError, type GamErrorEnvelope } from './errors.js';
import { ResultUnavailableError, type DateRange, type ReportQuery, type RowsPage, type StoredReport } from './gam-client.js';
import type { Logger } from './log.js';
import type { ToolContext } from './report-tool-builder.js';

import { buildTable, type Cell, type Column } from './values.js';
import { encodeCursor, decodeCursor } from './cursor.js';
import { envelope, inferSchema, type DateSpan, type InputReport, type ResultEnvelope } from './envelope.js';

export const GAM_MAX_PAGE_ROWS = 10_000;
export const DEFAULT_PAGE_ROWS = 5_000;
// ponytail: fixed ceiling on rows a computing tool reads; page its output if a real network needs more.
export const MAX_INPUT_ROWS = 50_000;

export type ReportRequest = {
  query: ReportQuery;
  dateRange: DateRange;
  summary: string;
  warnings?: string[];
};

export type ReportRows = {
  columns: Column[];
  rows: Record<string, Cell>[];
  input: InputReport;
  warnings: string[];

export function resolvePageRows(raw: string | undefined, logger: Logger): number | { error: string } {
  if (raw === undefined) return DEFAULT_PAGE_ROWS;
  const n = Number(raw);
  if (!Number.isInteger(n) || n < 1) return { error: `GAM_PAGE_ROWS must be a positive integer, got ${raw}` };
  if (n > GAM_MAX_PAGE_ROWS) {
    logger.info('config.page_rows_clamped', { requested: n, used: GAM_MAX_PAGE_ROWS });
    return GAM_MAX_PAGE_ROWS;
  }
  return n;
}

export function pageRows(ctx: ToolContext): number {
  return Math.min(ctx.pageRows ?? DEFAULT_PAGE_ROWS, GAM_MAX_PAGE_ROWS);
}

const realSleep = (ms: number) => new Promise<void>((r) => setTimeout(r, ms));

// The only polling loop in the server.
export async function pollUntilDone(
  ctx: ToolContext,
  operation: string,
): Promise<{ result: string } | GamErrorEnvelope> {
  const timeoutMs = ctx.reportTimeoutMs ?? 300_000;
  const sleep = ctx.sleep ?? realSleep;
  const start = Date.now();
  let delay = 2000;
  for (;;) {
    const s = await ctx.client.pollOperation(operation);
    const elapsed_ms = Date.now() - start;
    ctx.logger.debug('report.poll', { operation, state: s.state, elapsed_ms });
    if (s.state === 'done') {
      ctx.logger.info('report.done', { operation, total_elapsed_ms: elapsed_ms });
      return { result: s.result };
    }
    if (s.state === 'failed') {
      ctx.logger.warn('report.failed', { operation, reason: s.reason });
      return gamError('REPORT_FAILED', { reason: s.reason, operation });
    }
    if (elapsed_ms + delay > timeoutMs) {
      ctx.logger.error('report.timeout', { operation, timeout_ms: timeoutMs });
      return gamError('REPORT_TIMEOUT', { timeout_ms: timeoutMs, operation });
    }
    await sleep(delay);
    delay = Math.min(delay * 1.5, 15_000);
  }
}

// Creates the report for a definition, runs it and waits for the result.
async function runToResult(
  ctx: ToolContext,
  definition: ReportDefinition,
): Promise<{ report: string; result: string } | GamErrorEnvelope> {
  const range = definitionRange(definition);
  ctx.logger.debug('report.create', {
    dimensions: definition.dimensions,
    metrics: definition.metrics,
    date_start: range?.start ?? null,
    date_end: range?.end ?? null,
  });
  const { report } = await ctx.client.defineReport(definition);
  const { operation } = await ctx.client.runReport(report);
  const done = await pollUntilDone(ctx, operation);
  return 'error' in done ? done : { report, result: done.result };
}

function toGamError(e: unknown): GamErrorEnvelope {
  if (e instanceof ResultUnavailableError) return gamError('REPORT_RESULT_EXPIRED', { result: e.result });
  return gamError('INTERNAL_ERROR', { reason: e instanceof Error ? e.message : String(e) });
}

// What a result's first page says about the whole result. GAM sends these on
// the first page only.
type ResultFacts = {
  run_time: string | null;
  date_range: DateSpan | null;
  total_row_count: number | null;
};

// A first page with no totalRowCount and no further page has exactly its own
// rows: proto3 JSON omits zero. With a further page the count is unknown.
function firstPageTotal(page: RowsPage): number | null {
  return page.totalRowCount ?? (page.nextPageToken ? null : page.rows.length);
}

function factsOf(page: RowsPage): ResultFacts {
  return {
    run_time: page.runTime ?? null,
    date_range: page.dateRanges?.[0] ?? null,
    total_row_count: firstPageTotal(page),
  };
}

type FirstPage = {
  report: string;
  result: string;
  page: RowsPage;
  facts: ResultFacts;
  // True when an earlier call produced the result (spec §1.1).
  cacheHit: boolean;
};

// The one step both report functions share: obtain the result that answers a
// definition, and read its first page. Report reuse, shared runs, the result
// cache and the re-run of an expired cached result all live here (spec §2.1).
async function firstPage(
  ctx: ToolContext,
  definition: ReportDefinition,
  pageSize: number,
): Promise<FirstPage | GamErrorEnvelope> {
  const ran = await runToResult(ctx, definition);
  if ('error' in ran) return ran;
  const page = await ctx.client.fetchRows(ran.result, { pageSize });
  return { report: ran.report, result: ran.result, page, facts: factsOf(page), cacheHit: false };
}

// Definition-derived caveats (reach non-additivity, the alias/KV rewrite
// notes, ...) are only computed once, for the first page. A later page has
// no access to them, so rather than silently drop them it points back at
// where they live. PR 2 rebuilds them per page instead of pointing back.
const CAVEATS_ON_FIRST_PAGE =
  'Caveats that apply to this whole report are listed on its first page; read them with these rows.';

type PageArgs = {
  ctx: ToolContext;
  report: string;
  result: string;
  definition: ReportDefinition;
  summary: string;
  warnings: string[];
  page: RowsPage;
  offset: number;
  total: number | null;
  runTime: string | null;
  dateRange: DateSpan | null;
  cacheHit: boolean;
};

function pageEnvelope(a: PageArgs): ResultEnvelope {
  const table = buildTable(a.definition.dimensions, a.definition.metrics, a.page.rows);
  const returned = table.rows.length;
  const nextCursor = a.page.nextPageToken
    ? encodeCursor({
        result: a.result,
        page_token: a.page.nextPageToken,
        offset: a.offset + returned,
        total_row_count: a.total,
        run_time: a.runTime,
        date_range: a.dateRange,
      })
    : null;
  const warnings = [...a.warnings, ...table.warnings];
  if (a.dateRange === null) warnings.push('GAM did not report the computed date range for this result.');
  if (a.total === null) {
    warnings.push('GAM did not report how many rows this result has.');
  } else if (!nextCursor && a.offset + returned < a.total) {
    warnings.push(`GAM reported ${a.total} rows but returned ${a.offset + returned} and no further page.`);
  }
  return envelope({
    summary: a.summary,
    provenance: {
      network_code: a.ctx.networkCode,
      report_type: a.definition.reportType,
      report: a.report,
      result: a.result,
      run_time: a.runTime,
      date_range: a.dateRange,
      date_time_zone: a.ctx.timezone,
      dimensions: a.definition.dimensions,
      metrics: a.definition.metrics,
      filters: a.definition.filters ?? [],
      sort: a.definition.sorts ?? [],
      cache: { hit: a.cacheHit },
    },
    total_row_count: a.total,
    truncated: nextCursor !== null || (a.total !== null && a.offset + returned < a.total),
    next_cursor: nextCursor,
    warnings,
    schema: table.columns,
    rows: table.rows,
  });
}

export async function executeReport(
  ctx: ToolContext,
  req: ReportRequest,
): Promise<ResultEnvelope | GamErrorEnvelope> {
  try {
    const definition = reportDefinition(req.query, req.dateRange);
    const first = await firstPage(ctx, definition, pageRows(ctx));
    if ('error' in first) return first;
    return pageEnvelope({
      ctx,
      report: first.report,
      result: first.result,
      definition,
      summary: req.summary,
      warnings: req.warnings ?? [],
      page: first.page,
      offset: 0,
      total: first.facts.total_row_count,
      runTime: first.facts.run_time,
      dateRange: first.facts.date_range,
      cacheHit: first.cacheHit,
    });
  } catch (e) {
    return toGamError(e);
  }
}

// Stored definitions never change (reports are never patched), so they can be
// remembered per client for the life of the process.
const storedReports = new WeakMap<object, Map<string, StoredReport>>();
const STORED_REPORTS_MAX = 1000;

async function storedReport(ctx: ToolContext, report: string): Promise<StoredReport | null> {
  let byName = storedReports.get(ctx.client);
  if (!byName) storedReports.set(ctx.client, (byName = new Map()));
  const hit = byName.get(report);
  if (hit) return hit;
  const found = await ctx.client.getReport(report);
  if (found) {
    if (byName.size >= STORED_REPORTS_MAX) byName.delete(byName.keys().next().value!);
    byName.set(report, found);
  }
  return found;
}

export async function fetchReportPage(
  ctx: ToolContext,
  cursorText: string,
): Promise<ResultEnvelope | GamErrorEnvelope> {
  const cursor = decodeCursor(cursorText, ctx.networkCode);
  if ('error' in cursor) {
    return gamError('INVALID_INPUT', {
      reason: cursor.error,
      hint: 'Pass next_cursor exactly as a previous result returned it.',
    });
  }
  const report = cursor.result.slice(0, cursor.result.indexOf('/results/'));
  try {
    const stored = await storedReport(ctx, report);
    if (!stored) return gamError('REPORT_RESULT_EXPIRED', { result: cursor.result });
    const page = await ctx.client.fetchRows(cursor.result, { pageSize: pageRows(ctx), pageToken: cursor.page_token });
    const last = cursor.offset + page.rows.length;
    // A missing count from GAM is only unknowable while more pages remain —
    // on the page that turns out to be the last one, the total is exactly
    // what's been seen so far.
    const total = cursor.total_row_count ?? (page.nextPageToken ? null : last);
    return pageEnvelope({
      ctx,
      report,
      result: cursor.result,
      definition: stored.definition,
      summary: `Rows ${cursor.offset + 1}–${last} of ${total ?? 'an unreported number'} from ${report}`,
      warnings: [CAVEATS_ON_FIRST_PAGE],
      page,
      offset: cursor.offset,
      total,
      runTime: cursor.run_time,
      dateRange: cursor.date_range,
      cacheHit: false,
    });
  } catch (e) {
    return toGamError(e);
  }
}

function tooLarge(rows: number, limit: number, what: string): GamErrorEnvelope {
  return gamError('RESULT_TOO_LARGE', { rows, limit, what });
}

export async function executeReportRows(
  ctx: ToolContext,
  query: ReportQuery,
  dateRange: DateRange,
): Promise<ReportRows | GamErrorEnvelope> {
  try {
    const definition = reportDefinition(query, dateRange);
    const first = await firstPage(ctx, definition, GAM_MAX_PAGE_ROWS);
    if ('error' in first) return first;
    const reported = first.facts.total_row_count;
    if (reported !== null && reported > MAX_INPUT_ROWS) return tooLarge(reported, MAX_INPUT_ROWS, 'input report');
    const pages: RowsPage[] = [first.page];
    let count = first.page.rows.length;
    let token = first.page.nextPageToken;
    while (token) {
      const page = await ctx.client.fetchRows(first.result, { pageSize: GAM_MAX_PAGE_ROWS, pageToken: token });
      count += page.rows.length;
      if (count > MAX_INPUT_ROWS) return tooLarge(count, MAX_INPUT_ROWS, 'input report');
      pages.push(page);
      token = page.nextPageToken;
    }
    const table = buildTable(definition.dimensions, definition.metrics, pages.flatMap((p) => p.rows));
    const warnings = [...table.warnings];
    const reportedTotal = first.page.totalRowCount;
    if (reportedTotal !== undefined && reportedTotal !== count) {
      warnings.push(
        `GAM reported ${reportedTotal} rows for ${first.result} but served ${count}; results below were computed from ${count} rows.`,
      );
    }
    return {
      columns: table.columns,
      rows: table.rows,
      warnings,
      input: {
        report: first.report,
        result: first.result,
        run_time: first.facts.run_time,
        date_range: first.facts.date_range,
      },
    };
  } catch (e) {
    return toGamError(e);
  }
}

export function derivedEnvelope(
  ctx: ToolContext,
  d: { summary: string; inputs: InputReport[]; rows: Record<string, unknown>[]; warnings?: string[] },
): ResultEnvelope | GamErrorEnvelope {
  const limit = pageRows(ctx);
  if (d.rows.length > limit) return tooLarge(d.rows.length, limit, 'output');
  return envelope({
    summary: d.summary,
    provenance: { network_code: ctx.networkCode, date_time_zone: ctx.timezone, inputs: d.inputs },
    total_row_count: d.rows.length,
    truncated: false,
    next_cursor: null,
    warnings: d.warnings ?? [],
    schema: inferSchema(d.rows),
    rows: d.rows,
  });
}
```

### Task 2: Later pages report the server's facts and caveats, never the cursor's

A cursor is not signed, so its copies of `run_time`, `date_range` and `total_row_count` must not reach provenance (PR 1 review). The server remembers each result's first-page facts in a bounded per-client map (the same three values the cache's `done` entry will hold), and on a miss — after a restart, say — reads page 1 again with `pageSize=1`.
```ts
// A Map bounded by entry count. Reading or writing an entry makes it the most
// recently used; beyond `max`, the least recently used entry is dropped.
export class Lru<K, V> {
  private readonly map = new Map<K, V>();

  constructor(private readonly max: number) {}

  get(key: K): V | undefined {
    const value = this.map.get(key);
    if (value !== undefined) {
      this.map.delete(key);
      this.map.set(key, value);
    }
    return value;
  }

  set(key: K, value: V): void {
    this.map.delete(key);
    this.map.set(key, value);
    if (this.map.size > this.max) this.map.delete(this.map.keys().next().value as K);
  }

  delete(key: K): void {
    this.map.delete(key);
  }

  get size(): number {
    return this.map.size;
  }
}
```

```ts
// process): stored definitions, which never change because reports are never
// patched, and each result's first-page facts, which later pages report
// instead of trusting a cursor.
type ClientMemory = {
  stored: Lru<string, StoredReport>;
  facts: Lru<string, ResultFacts>;
};

const memories = new WeakMap<object, ClientMemory>();

function clientMemory(ctx: ToolContext): ClientMemory {
  let memory = memories.get(ctx.client);
  if (!memory) {
    memory = { stored: new Lru(REMEMBERED_RESULTS_MAX), facts: new Lru(REMEMBERED_RESULTS_MAX) };
    memories.set(ctx.client, memory);
  }
  return memory;
}

async function storedReport(ctx: ToolContext, report: string): Promise<StoredReport | null> {
  const { stored } = clientMemory(ctx);
  const known = stored.get(report);
  if (known) return known;
  const found = await ctx.client.getReport(report);
  if (found) stored.set(report, found);
  return found;
}

// A result's first-page facts: those of the first page this process served,
// or GAM's own, read again with a one-row page. A cursor's copies are never
// used, because a cursor is not signed.
async function resultFacts(ctx: ToolContext, result: string): Promise<ResultFacts> {
  const { facts } = clientMemory(ctx);
  const known = facts.get(result);
  if (known) return known;
  const fresh = factsOf(await ctx.client.fetchRows(result, { pageSize: 1 }));
  facts.set(result, fresh);
  return fresh;
}
```

```ts
async function httpError(call: string, res: Response): Promise<GamHttpError> {
  const text = await res.text();
  let gamStatus: string | undefined;

    if (typeof status === 'string') gamStatus = status;

  return new GamHttpError(call, res.status, gamStatus, text.slice(0, 500));
}

// GAM reports a result it no longer serves as NOT_FOUND or FAILED_PRECONDITION

function namesResult(err: GamHttpError, result: string): boolean {
  if (err.gamStatus !== 'NOT_FOUND' && err.gamStatus !== 'FAILED_PRECONDITION') return false;

}
```

```ts
// Retries transient failures with exponential backoff (spec §2.3). A GET is
// retried on a thrown fetch, 429 and 5xx. A POST is retried only on 429, the
// one answer that means GAM did not act on it: after a 5xx or a lost
// connection the report may already exist, and the next identical call finds
// it by name instead of creating a second one. Other 4xx answers return at once.
export function withRetries(
  fetchImpl: typeof fetch,
  opts: { maxAttempts?: number; baseDelayMs?: number; logger?: Logger } = {},
): typeof fetch {
  const maxAttempts = opts.maxAttempts ?? 4; // 1 initial + 3 retries
  const baseDelay = opts.baseDelayMs ?? 250;
  const logger = opts.logger ?? noopLogger();
  return (async (input: RequestInfo | URL, init?: RequestInit) => {
    const method = (init?.method ?? (input instanceof Request ? input.method : 'GET')).toUpperCase();
    const post = method === 'POST';
    let lastErr: unknown;
    for (let attempt = 0; attempt < maxAttempts; attempt++) {
      let res: Response;
      try {
        res = await fetchImpl(input, init);
      } catch (e) {
        lastErr = e;
        const message = e instanceof Error ? e.message : String(e);
        if (post || attempt === maxAttempts - 1) {
          logger.error('gam.fetch_failed', { method, message, attempt: attempt + 1, max_attempts: maxAttempts });
          throw e;
        }
        const delay_ms = baseDelay * 2 ** attempt;
        logger.warn('gam.retry', { method, message, attempt: attempt + 1, max_attempts: maxAttempts, delay_ms });
        await sleepWithJitter(delay_ms);
        continue;
      }
      const retryable = res.status === 429 || (!post && res.status >= 500);
      if (!retryable || attempt === maxAttempts - 1) return res;
      const delay_ms = baseDelay * 2 ** attempt;
      logger.warn('gam.retry', { method, status: res.status, attempt: attempt + 1, max_attempts: maxAttempts, delay_ms });
      await sleepWithJitter(delay_ms);
    }
    throw lastErr ?? new Error('unreachable: retry loop exhausted');
  }) as typeof fetch;
}
```

```ts
// Time zones as the report path needs them (spec §2.4): GAM computes days in
// the network's zone, while GAM_TIMEZONE chooses which calendar dates to ask
// for. The two may differ as long as their UTC offsets agree on every day a
// result covers.

const MINUTE = 60_000;
const DAY = 24 * 60 * MINUTE;
// Transitions happen on quarter-hour boundaries in every zone in use.
const STEP = 15 * MINUTE;
const ISO_DATE = /^\d{4}-\d{2}-\d{2}$/;

// The canonical IANA name for a zone, or null if this runtime does not know it.
export function canonicalTimeZone(name: string): string | null {
  try {
    return new Intl.DateTimeFormat('en-US', { timeZone: name }).resolvedOptions().timeZone;
  } catch {
    return null;
  }
}

const formatters = new Map<string, Intl.DateTimeFormat>();

function formatter(zone: string): Intl.DateTimeFormat {
  let f = formatters.get(zone);
  if (!f) {
    f = new Intl.DateTimeFormat('en-US', { timeZone: zone, timeZoneName: 'longOffset' });
    formatters.set(zone, f);
  }
  return f;
}

// Minutes east of UTC at an instant. Intl writes the offset as "GMT",
// "GMT+08:00" or "GMT-04:30".
export function offsetMinutes(zone: string, at: number): number {
  const name = formatter(zone).formatToParts(new Date(at)).find((p) => p.type === 'timeZoneName')?.value ?? '';
  const m = /^GMT(?:([+-])(\d{2}):(\d{2}))?$/.exec(name);
  if (!m) throw new Error(`cannot read the UTC offset of ${zone} from ${JSON.stringify(name)}`);
  if (!m[1]) return 0;
  const minutes = Number(m[2]) * 60 + Number(m[3]);
  return m[1] === '-' ? -minutes : minutes;
}

// Whether two zones have different UTC offsets at any instant that can fall on
// a calendar day of `range` in either of them. Offsets are compared at every
// UTC midnight from the day before `start` to two days after `end`; a day on
// which either zone changes offset is also checked every 15 minutes. A range
// that cannot be read proves nothing, so it counts as differing.
export function offsetsDiffer(a: string, b: string, range: { start: string; end: string }): boolean {
  const first = Date.parse(`${range.start}T00:00:00Z`) - DAY;
  const last = Date.parse(`${range.end}T00:00:00Z`) + 2 * DAY;
  if (!Number.isFinite(first) || !Number.isFinite(last)) return true;
  for (let day = first; day < last; day += DAY) {
    const a0 = offsetMinutes(a, day);
    const b0 = offsetMinutes(b, day);
    if (a0 !== b0) return true;
    if (offsetMinutes(a, day + DAY) === a0 && offsetMinutes(b, day + DAY) === b0) continue;
    for (let t = day + STEP; t < day + DAY; t += STEP) {
      if (offsetMinutes(a, t) !== offsetMinutes(b, t)) return true;
    }
  }
  return false;
}

function readable(range: { start: string; end: string }): boolean {
  return ISO_DATE.test(range.start) && ISO_DATE.test(range.end) && range.start <= range.end;
}

// The warning a result carries when its dates were chosen in one zone and
// counted by GAM in another whose offsets differ (spec §2.4), or null.
export function zoneWarning(
  dateZone: string,
  reportZone: string,
  range: { start: string; end: string } | null,
): string | null {
  if (dateZone === reportZone) return null;
  const head = `Dates were chosen in ${dateZone} (GAM_TIMEZONE), but GAM counts each day in the network's time zone, ${reportZone}`;
  if (range && readable(range)) {
    if (!offsetsDiffer(dateZone, reportZone, range)) return null;
    return `${head}, and the two zones' UTC offsets differ on at least one day of ${range.start}..${range.end}: ` +
      'those days do not cover the same hours as the dates you asked for.';
  }
  return `${head}, and this result does not say which days it covers, so it cannot show that their day boundaries line up.`;
}
```

```ts
import { CredentialError, gamError } from './errors.js';
import { GamHttpError, type GAMClient, type NetworkInfo } from './gam-client.js';
import type { Logger } from './log.js';
import { canonicalTimeZone } from './zones.js';

export const DEFAULT_REPORT_TIMEOUT_MS = 300_000;
export const DEFAULT_REPORT_CACHE_TTL_MS = 3_600_000;

export type Settings = {
  // GAM_NETWORK_CODE, digits only: it is placed into resource names and into
  // the pattern cursors are checked against.
  networkCode: string;
  // GAM_TIMEZONE, canonicalised; undefined means "the network's zone".
  dateTimeZone: string | undefined;
  reportTimeoutMs: number;
  cacheTtlMs: number;
  cacheDir: string | undefined;
};

function integerSetting(
  env: NodeJS.ProcessEnv,
  name: string,
  fallback: number,
  min: number,
): number | { error: string } {
  const raw = env[name];
  if (raw === undefined || raw === '') return fallback;
  const n = Number(raw);
  if (!Number.isSafeInteger(n) || n < min) {
    return { error: `${name} must be a whole number of milliseconds, at least ${min}; got ${JSON.stringify(raw)}` };
  }
  return n;
}

// The settings that can be checked before any request. Each error names its
// variable; the caller stops startup with exit code 2.
export function readSettings(env: NodeJS.ProcessEnv): Settings | { error: string } {
  const networkCode = env.GAM_NETWORK_CODE;
  if (!networkCode) return { error: 'GAM_NETWORK_CODE is required' };
  if (!/^\d+$/.test(networkCode)) {
    return { error: `GAM_NETWORK_CODE must be the numeric network code, got ${JSON.stringify(networkCode)}` };
  }
  let dateTimeZone: string | undefined;
  const zone = env.GAM_TIMEZONE;
  if (zone !== undefined && zone !== '') {
    const canonical = canonicalTimeZone(zone);
    if (!canonical) {
      return { error: `GAM_TIMEZONE=${JSON.stringify(zone)} is not an IANA time zone name (for example Asia/Seoul)` };
    }
    dateTimeZone = canonical;
  }
  const reportTimeoutMs = integerSetting(env, 'GAM_REPORT_TIMEOUT_MS', DEFAULT_REPORT_TIMEOUT_MS, 1);
  if (typeof reportTimeoutMs !== 'number') return reportTimeoutMs;
  const cacheTtlMs = integerSetting(env, 'GAM_REPORT_CACHE_TTL_MS', DEFAULT_REPORT_CACHE_TTL_MS, 0);
  if (typeof cacheTtlMs !== 'number') return cacheTtlMs;
  return { networkCode, dateTimeZone, reportTimeoutMs, cacheTtlMs, cacheDir: env.GAM_REPORT_CACHE_DIR || undefined };
}

// networks.get with the configured credential, before anything is served
// (spec §2.4). The error names the credential source and what GAM answered,
// never anything the credential contains.
export async function checkNetworkIdentity(
  client: Pick<GAMClient, 'getNetwork'>,
  networkCode: string,
  source: 'file' | 'json' | 'adc',
): Promise<NetworkInfo | { error: string }> {
  let network: NetworkInfo;
  try {
    network = await client.getNetwork();
  } catch (e) {
    return {
      error: `cannot read network ${networkCode} with the ${source} credential (${describeFailure(e)}).\n` +
        `  hint: ${gamError('AUTH_FAILED').error.hint}`,
    };
  }
  const timeZone = canonicalTimeZone(network.timeZone);
  if (!timeZone) {
    return {
      error: `network ${networkCode} reports the time zone ${JSON.stringify(network.timeZone)}, which this Node runtime does not know`,
    };
  }
  return { ...network, timeZone };
}

function describeFailure(e: unknown): string {
  if (e instanceof GamHttpError) return `GAM answered HTTP ${e.status}${e.gamStatus ? ` ${e.gamStatus}` : ''}`;
  if (e instanceof CredentialError) return `GAM was not reached: ${e.message}`;
  return `GAM could not be read: ${e instanceof Error ? e.message : String(e)}`;
}

// GAM_TIMEZONE chooses calendar dates; unset, it is the network's zone, and a
// different zone is allowed (spec D-4). One line names both zones.
export function chooseDateTimeZone(setting: string | undefined, network: NetworkInfo, logger: Logger): string {
  const dateTimeZone = setting ?? network.timeZone;
  logger.info('startup.identity', {
    network_code: network.networkCode,
    currency_code: network.currencyCode,
```

```ts
async function main(): Promise<void> {

  // free for normal logging since MCP frames go over HTTP, not stdout.

  if ('error' in settings) stop(settings.error);

      reason: 'results are paged; set GAM_PAGE_ROWS instead',
    });
  }

  const resolved = resolveAuthSource(process.env);
  if ('error' in resolved) stop(`${resolved.error.message}\n  hint: ${resolved.error.hint}`);
  logger.info('auth.source_resolved', { source: resolved.source.type });

  // Transient failures are retried with backoff; a POST only on 429 (spec §2.3).
  const fetchImpl = withRetries(createAuthFetch(auth), { logger });
  const rawClient = createRestGamClient({ networkCode, fetchImpl });

  // Nothing is served until the credential has read the network (spec §2.4).
  const network = await checkNetworkIdentity(rawClient, networkCode, resolved.source.type);
  if ('error' in network) stop(network.error);
  const timezone = chooseDateTimeZone(settings.dateTimeZone, network, logger);

  const usageCounters = createUsageCounters();
  const client = instrumentGamClient(rawClient, usageCounters);
  const reportCache = createReportCache({
    logger,
    ttlMs: settings.cacheTtlMs,
    ...(settings.cacheDir ? { diskDir: settings.cacheDir } : {}),
  });
  const savedQueries = createSavedQueryStore(defaultSavedQueriesPath(process.env));
  const ctx = {
    client,
    timezone,
    networkCode,
    pageRows,
    reportTimeoutMs: settings.reportTimeoutMs,
    reportCache,
    logger,
    savedQueries,
    usageCounters,

    await startMcpServer(ctx, { networkCode });
```

```ts
import { createHash } from 'node:crypto';
import type { ReportDefinition } from './report-definition.js';

type Json = null | boolean | number | string | Json[] | { [key: string]: Json };

// Object keys sorted at every depth, so key order never changes the text.
function sortKeys(v: unknown): Json {
  if (Array.isArray(v)) return v.map(sortKeys);
  if (v !== null && typeof v === 'object') {
    const out: { [key: string]: Json } = {};
    for (const k of Object.keys(v).sort()) {
      const x = (v as Record<string, unknown>)[k];
      if (x !== undefined) out[k] = sortKeys(x);
    }
    return out;
  }
  return v as Json;
}

const text = (v: unknown): string => JSON.stringify(sortKeys(v));

function byText(a: unknown, b: unknown): number {
  const x = text(a);
  const y = text(b);
  return x < y ? -1 : x > y ? 1 : 0;
}

// A filter with the values inside it in a fixed order.
function normalizeFilter(f: unknown): unknown {
  const field = (f as { fieldFilter?: { values?: unknown } } | null)?.fieldFilter;
  if (!field || !Array.isArray(field.values)) return f;
  return { ...(f as object), fieldFilter: { ...field, values: [...field.values].sort(byText) } };
}

// The form of a definition that is hashed and compared (spec §2.2). GAM gives
// no meaning to the order of dimensions, metrics, filters or the values inside
// a filter, so those are sorted. customDimensionKeyIds are positional (slot N
// is CUSTOM_DIMENSION_N_VALUE) and every other list keeps its order. Absent
// fields and empty lists are dropped: GAM's JSON omits empty lists, so a
// definition read back from GAM has none.
export function canonicalDefinition(def: ReportDefinition): Json {
  const out: Record<string, unknown> = {};
  for (const [key, value] of Object.entries(def)) {
    if (value === undefined || value === null || (Array.isArray(value) && value.length === 0)) continue;
    if (key === 'dimensions' || key === 'metrics') out[key] = [...(value as string[])].sort();
    else if (key === 'filters') out[key] = (value as unknown[]).map(normalizeFilter).sort(byText);
    else out[key] = value;
  }
  return sortKeys(out);
}

// SHA-256 of the canonical definition. It is the result-cache key and the
// source of the report name: both come from this one function (test E7).
export function definitionHash(def: ReportDefinition): string {
  return createHash('sha256').update(JSON.stringify(canonicalDefinition(def))).digest('hex');
}

// The displayName of the report that runs a definition, so any process can
// find that report again by listing the name (spec §2.2).
export function reportName(hash: string): string {
  return `gam-mcp ${hash.slice(0, 16)}`;
}

export function sameDefinition(a: ReportDefinition, b: ReportDefinition): boolean {
  return JSON.stringify(canonicalDefinition(a)) === JSON.stringify(canonicalDefinition(b));
}
```

```ts
import { ReportFilterRejectedError, type GAMClient } from './gam-client.js';
import type { Logger } from './log.js';
import { definitionRange, type ReportDefinition } from './report-definition.js';
import { reportName, sameDefinition } from './report-key.js';
import { Lru } from './lru.js';

// Report names remembered per client; the server builds one client per process.
export const REUSE_MAP_MAX = 1000;

type ReuseState = { byKey: Lru<string, string>; filterRejectionLogged: boolean };
const states = new WeakMap<object, ReuseState>();

function stateFor(client: GAMClient): ReuseState {
  let state = states.get(client);
  if (!state) {
    state = { byKey: new Lru(REUSE_MAP_MAX), filterRejectionLogged: false };
    states.set(client, state);
  }
  return state;
}

// The report that runs `definition` (spec §2.2): one this process already
// used, else one GAM lists under the definition's name whose stored
// definition is the same after normalisation, else a new one. `key` is
// definitionHash(definition), the same value the report is named from.
export async function findOrCreateReport(
  ctx: { client: GAMClient; logger: Logger },
  definition: ReportDefinition,
  key: string,
  tool: string,
): Promise<string> {
  const state = stateFor(ctx.client);
  const known = state.byKey.get(key);
  if (known) return known;
  const displayName = reportName(key);
  let report: string | undefined;
  try {
    const listed = await ctx.client.listReports({ displayName });
    report = listed.find((r) => sameDefinition(r.definition, definition))?.name;
    if (!report && listed.length > 0) {
      ctx.logger.warn('report.name_taken', { tool, display_name: displayName, listed: listed.length });
    }
  } catch (e) {
    if (!(e instanceof ReportFilterRejectedError)) throw e;
    // Without the filter there is no cheap way to find the report: create one.
    if (!state.filterRejectionLogged) {
      state.filterRejectionLogged = true;
      ctx.logger.warn('report.list_filter_rejected', { tool, status: e.status });
    }
  }
  if (report) {
    ctx.logger.debug('report.reused', { tool, report, display_name: displayName });
  } else {
    const range = definitionRange(definition);
    ctx.logger.info('report.create', {
      tool,
      display_name: displayName,
      dimensions: definition.dimensions,
      metrics: definition.metrics,
      date_start: range?.start ?? null,
      date_end: range?.end ?? null,
    });
    report = (await ctx.client.defineReport(definition)).report;
  }
  state.byKey.set(key, report);
  return report;
}
```

```ts
// Which GAM result answers a definition — never the rows (spec §2.5).
export type DoneEntry = {
  kind: 'done';
  report: string;
  result: string;
  run_time: string | null;
  date_range: DateSpan | null;
  total_row_count: number | null;
  stored_at: string;
};

// A run that outlived its caller's timeout. The next identical call waits for
// this operation instead of starting another (spec §2.6).
export type PendingEntry = {
  kind: 'pending';
  report: string;
  operation: string;
  started_at: string;
};

export type CacheEntry = DoneEntry | PendingEntry;

export type ReportCache = {
  // The live entry for a key (a definition hash). A done entry counts as a
  // hit; no entry, or a pending one, counts as a miss.
  get(key: string): CacheEntry | undefined;
  putDone(key: string, entry: Omit<DoneEntry, 'kind' | 'stored_at'>): void;
  // A pending run recorded again keeps its original started_at.
  putPending(key: string, entry: { report: string; operation: string; started_at?: string }): void;
  delete(key: string): void;
  size(): number;
  // Session hit and miss counts, for usage_stats.
  stats(): { hits: number; misses: number };
};

export const CACHE_MAX_ENTRIES = 1000;
export const PENDING_TTL_MS = 3_600_000;
const DEFAULT_TTL_MS = 3_600_000;

function isSpan(v: unknown): v is DateSpan {
  return typeof v === 'object' && v !== null
    && typeof (v as DateSpan).start === 'string' && typeof (v as DateSpan).end === 'string';
}

// An entry read from disk, or undefined if the file holds anything else.
function parseEntry(v: unknown): CacheEntry | undefined {
  if (typeof v !== 'object' || v === null) return undefined;
  const e = v as Record<string, unknown>;
  if (e.kind === 'pending'
    && typeof e.report === 'string' && typeof e.operation === 'string' && typeof e.started_at === 'string') {
    return { kind: 'pending', report: e.report as string, operation: e.operation as string, started_at: e.started_at as string };
  }
  if (e.kind === 'done'
    && typeof e.report === 'string' && typeof e.result === 'string' && typeof e.stored_at === 'string'
    && (e.run_time === null || typeof e.run_time === 'string')
    && (e.date_range === null || isSpan(e.date_range))
    && (e.total_row_count === null || (Number.isSafeInteger(e.total_row_count) && (e.total_row_count as number) >= 0))) {
    return {
      kind: 'done',
      report: e.report as string,
      result: e.result as string,
      run_time: e.run_time as string | null,
      date_range: e.date_range === null ? null : { start: (e.date_range as DateSpan).start, end: (e.date_range as DateSpan).end },
      total_row_count: e.total_row_count as number | null,
      stored_at: e.stored_at as string,
    };
  }
  return undefined;
}

  const memory = new Lru<string, CacheEntry>(CACHE_MAX_ENTRIES);
  if (dir) mkdirSync(dir, { recursive: true });

  const message = (e: unknown) => (e instanceof Error ? e.message : String(e));
  // An unreadable timestamp is not live.
  const live = (e: CacheEntry): boolean =>
    e.kind === 'done'
      ? now() - Date.parse(e.stored_at) < ttlMs
      : now() - Date.parse(e.started_at) < PENDING_TTL_MS;

  function readDisk(key: string): CacheEntry | undefined {
    if (!dir) return undefined;
    let text: string;
    try {
      text = readFileSync(join(dir, `${key}.json`), 'utf8');
    } catch (e) {
      if ((e as NodeJS.ErrnoException).code !== 'ENOENT') {
        logger.warn('cache.disk_read_failed', { key: short(key), message: message(e) });
      }
      return undefined;
    }
    let entry: CacheEntry | undefined;
    try {
      entry = parseEntry(JSON.parse(text));
    } catch {
      entry = undefined;
    }
    if (!entry) logger.warn('cache.disk_entry_invalid', { key: short(key) });
    return entry;
  }

  // Written under a temporary name and renamed, so a reader never sees half a file.
  function writeDisk(key: string, entry: CacheEntry): void {
    if (!dir) return;
    const path = join(dir, `${key}.json`);
    const tmp = `${path}.${process.pid}.tmp`;
    try {
      writeFileSync(tmp, JSON.stringify(entry));
      renameSync(tmp, path);
    } catch (e) {
      logger.warn('cache.disk_write_failed', { key: short(key), message: message(e) });
    }
  }

  function removeDisk(key: string): void {
    if (!dir) return;
    try {
      unlinkSync(join(dir, `${key}.json`));
    } catch (e) {
      if ((e as NodeJS.ErrnoException).code !== 'ENOENT') {
        logger.warn('cache.disk_delete_failed', { key: short(key), message: message(e) });
      }
    }
  }

  function put(key: string, entry: CacheEntry): void {
    memory.set(key, entry);
    writeDisk(key, entry);
  }

  function remove(key: string): void {
    memory.delete(key);
    removeDisk(key);
  }

  return {
    get(key) {
      let entry = memory.get(key);
      if (!entry) {
        entry = readDisk(key);
        if (entry) memory.set(key, entry);
      }
      if (entry && !live(entry)) {
        remove(key);
        entry = undefined;
      }
      if (entry?.kind === 'done') {
        hits += 1;
        logger.debug('cache.hit', { key: short(key) });
      } else {
        misses += 1;
        logger.debug('cache.miss', { key: short(key), pending: entry !== undefined });
      }
      return entry;
    },
    putDone(key, e) {
      if (ttlMs === 0) {
        remove(key);
        return;
      }
      put(key, {
        kind: 'done',
        report: e.report,
        result: e.result,
        run_time: e.run_time,
        date_range: e.date_range,
        total_row_count: e.total_row_count,
        stored_at: iso(now()),
      });
    },
    putPending(key, e) {
      put(key, { kind: 'pending', report: e.report, operation: e.operation, started_at: e.started_at ?? iso(now()) });
    },
    delete: remove,
    size: () => memory.size,
    stats: () => ({ hits, misses }),
  };
}
```

```ts
async function firstPage(
  ctx: ToolContext,
  definition: ReportDefinition,
  pageSize: number,
  tool: string,
): Promise<FirstPage | GamErrorEnvelope> {
  // One function names the report and keys the cache (spec §2.2, test E7).
  const key = definitionHash(definition);
  for (let attempt = 0; ; attempt++) {
    const got = await obtainResult(ctx, definition, key, tool, attempt === 0);
    if ('error' in got) return got;
    let page: RowsPage;
    try {
      page = await ctx.client.fetchRows(got.result, { pageSize });
    } catch (e) {
      // A cached result GAM no longer serves is dropped and the report run
      // once more. A fresh result that is already gone is an error.
      if (e instanceof ResultUnavailableError && got.cached && attempt === 0) {
        ctx.logger.info('report.cached_result_gone', { tool, result: got.result });
        ctx.reportCache?.delete(key);
        continue;
      }
      throw e;
    }
    // A hit keeps the facts of the call that produced the result.
    const facts: ResultFacts = got.cached
      ? { run_time: got.cached.run_time, date_range: got.cached.date_range, total_row_count: got.cached.total_row_count }
      : factsOf(page);
    if (!got.cached) ctx.reportCache?.putDone(key, { report: got.report, result: got.result, ...facts });
    clientMemory(ctx).facts.set(got.result, facts);
    return { report: got.report, result: got.result, page, facts, cacheHit: got.cached !== null };
  }
}
```

```ts
// Finds or creates the report for `key` and runs it, or resumes the run a
// timed-out call left behind, then waits. A wait that ends because GAM says
// the run failed forgets the key; any other ending leaves a pending entry,
// because GAM may still be running the report.
async function runOnce(
  ctx: ToolContext,
  definition: ReportDefinition,
  key: string,
  tool: string,
  pending: PendingEntry | undefined,
): Promise<Obtained | GamErrorEnvelope> {
  let report: string;
  let operation: string;
  if (pending) {
    report = pending.report;
    operation = pending.operation;
    ctx.logger.info('report.resume', { tool, report, operation, started_at: pending.started_at });
  } else {
    report = await findOrCreateReport(ctx, definition, key, tool);
    operation = (await ctx.client.runReport(report)).operation;
  }
  const done = await pollUntilDone(ctx, operation);
  if (!('error' in done)) return { report, result: done.result, cached: null };
  if (done.error.code === 'REPORT_FAILED') {
    ctx.reportCache?.delete(key);
  } else {
    ctx.reportCache?.putPending(key, { report, operation, ...(pending && { started_at: pending.started_at }) });
  }
  return done;
}

// Spec §2.1 steps 3–6: join an identical run in flight, else use a live cached
// result, else resume a timed-out run, else start one. Every caller of a
// shared run gets its outcome, failures included; the flight is removed as
// soon as the run settles, so the next call starts fresh.
function obtainResult(
  ctx: ToolContext,
  definition: ReportDefinition,
  key: string,
  tool: string,
  useCache: boolean,
): Promise<Obtained | GamErrorEnvelope> {
  const { flights } = clientMemory(ctx);
  const joined = flights.get(key);
  if (joined) {
    ctx.logger.info('report.shared', { tool, key: key.slice(0, 16) });
    return joined;
  }
  const entry = useCache ? ctx.reportCache?.get(key) : undefined;
  if (entry?.kind === 'done') {
    ctx.logger.info('report.cache_hit', { tool, key: key.slice(0, 16), result: entry.result, run_time: entry.run_time });
    return Promise.resolve({ report: entry.report, result: entry.result, cached: entry });
  }
  const run = runOnce(ctx, definition, key, tool, entry?.kind === 'pending' ? entry : undefined);
  flights.set(key, run);
  const settle = () => {
    if (flights.get(key) === run) flights.delete(key);
  };
  run.then(settle, settle);
  return run;
}
```

### Choices beyond the letter of the spec (for the reviewer)

- A wait that ends in `QUOTA_EXCEEDED`, or in a poll that could not reach GAM, also records a `pending` entry: the operation is still alive, and repeating it would be a duplicate job. `REPORT_FAILED` — including a poll answered 404, meaning GAM no longer knows the operation — forgets the key instead.
- 401/403 from GAM during a call maps to `AUTH_FAILED` (was `INTERNAL_ERROR`); a `CredentialError` does too.
- `GAM_REPORT_TIMEOUT_MS` and `GAM_REPORT_CACHE_TTL_MS` are validated: `Number('soon')` would have made the timeout never fire.
- The disk tier is split per network, because the cache key does not name the network.
- The REST client fills in `dimensions`/`metrics` that GAM's JSON omits when empty; `fetch_report_page` and the reuse comparison both rely on them.
- REACH caveats moved from `reach_report`/`run_report` into `definitionWarnings`, so `run_report` REACH results now also carry the coverage caveat.
- The cursor format is unchanged (v1 still carries `run_time`, `date_range` and `total_row_count`); `fetch_report_page` ignores those copies.
- Reuse compares the stored definition strictly after normalisation. If live GAM echoes extra default fields, a fresh process creates a new report rather than reusing one (safe, but more report objects). Spec §7.3 step 3 repeats the call within one process, where the in-memory map hides the list path; PR 5's smoke script should also repeat it from a fresh process.
